# Supabase Auth Setup

This repo now assumes Supabase Auth is the cloud identity layer and the checked-in SQL migration in `supabase/migrations/20260612143000_auth_and_trip_model.sql` is the starting schema for trips, nodes, stories, media, shares, and source accounts.

## Environment

Set these in `.env.local`:

- `EXPO_PUBLIC_SUPABASE_URL`
- `EXPO_PUBLIC_SUPABASE_PUBLISHABLE_KEY`

The app already uses the custom scheme in `app.json`:

- `wanderable://auth?mode=signin`

Add that exact URL to the Supabase dashboard allow-list for mobile redirects.

## Supabase Dashboard Auth Config

1. In **Authentication -> URL Configuration** add:
   - `wanderable://auth?mode=signin`
2. In **Authentication -> Providers -> Email** enable email auth.
3. In **Authentication -> Providers -> Google** enable Google and add the same redirect URL to your Google OAuth client.
4. If you keep email confirmation enabled, the app will show a confirmation step after sign-up and wait for the user to come back through the email link.

## Client Behavior

- Email sign-in uses `signInWithPassword`.
- Email sign-up uses `signUp` with first and last name copied into auth user metadata for profile bootstrapping.
- Google sign-in uses `signInWithOAuth` plus Expo browser deep linking.
- Session persistence uses the repo's MMKV-backed storage adapter in `lib/storage.ts`.

## Authorization Model

- Owners can create and edit their own profiles, trips, days, nodes, media, route segments, voice notes, publications, and source accounts.
- Public viewers can only read trips that have a `trip_publications` row with `visibility = 'public_link'` and a non-null `published_at`.
- Missing-GPS and skipped media remain private because only `placement_status = 'placed'` is publicly readable.

## Notes

- The app no longer depends on `@react-native-async-storage/async-storage` for Supabase auth.
- `utils/supabase.ts` now re-exports the canonical MMKV-backed client from `lib/supabase.ts`.
- The repo currently does not include the Supabase CLI, so the migration is checked in directly instead of being generated by the CLI.
